# 100 人 AI 研发团队的计算资源容量模型

给定研发团队每天委派的任务和发起的实验，一个 24 小时统计周期会消耗多少推理与实验卡时？为了让这些任务按时运行，又要预留多少 GPU、CPU、内存和存储？本模型以 100 名研究员为基准，从会话、实验作业和工作区三类业务记录估算资源需求。研究资料截止于 2026 年 11 月 19 日。

在默认的 2028 年 AL4 情景中，每天 **40 个新实验候选**，每次训练占 **8 张 H100、运行 3 小时**。模型算得 **84 张 H100 等效配置**，其中推理 12 张、训练 64 张、评测与数据生成 8 张。这三个业务输入都是可替换的建模假设。实际采购还取决于已有设备、共享策略，以及多少实验原本就会由人发起。

## 快速复算

进入本目录，使用 Python 3.9 或更高版本。核心模型只用标准库。

```bash
python model.py
python model.py my_results examples/overrides.json
```

第一条命令将默认结果写入 `modelout/`；第二条命令把修改参数后的结果写入 `my_results/`。两个目录均包含 `forecasts.csv`（三年 × 三种情景）、`profiles.csv`（2028 年对照）、`sensitivity.csv`（逐项调参）和 `results.json`（全部结果）。完整输入、单位和选取理由分别列在生成的 `parameters.csv` 和 `fixed_parameters.csv` 中。

也可直接打开 [Excel 情景模型](capacity_model.xlsx)，修改「情景参数」和「系统参数」中的输入。Excel 与 Python 各自独立计算。用上述覆盖示例运行 Python，2028 年 AL4 的总卡数应为 102 张。

## 如何从业务活动预测资源

| 资源 | 2028 年 AL4 假设 | 计算过程和结果 |
| --- | --- | --- |
| 直接推理 | 人均平均在线 1.2 个会话，推理占空比 24%，峰均系数 1.7；70B BF16，四卡并行，上下文 16,384 Token | 输入和输出量分别按“在线会话 × 活跃时长 × 活跃时的 Token 速率”计算。扣除前缀缓存命中后，预填充和解码合计 **17.10 GPU·h/日**。峰值约 49 条序列，每组四卡可容纳 24 条，需要 **12 卡**。 |
| 训练实验 | 每人日均 0.4 个新候选，单次技术成功率 80%，失败后有 65% 概率再试一次 | 每日期望尝试数＝40 × [1＋(1－0.8) × 0.65]＝45.2。训练消耗 45.2 × 8 × 3＝**1,084.8 GPU·h/日**。按 75% 目标占用，每个八卡组每日可接 18 小时作业，共需向上取整为 8 组，即 **64 卡**。 |
| 评测与合成 | 每次尝试做 2 次双卡评测，每次 0.6 小时；合成数据另耗 0.5 GPU·h | 45.2 × (2 × 2 × 0.6＋0.5)＝**131.08 GPU·h/日**；按双卡成组、75% 目标占用，配置 **8 卡**。 |
| 执行环境 | 120 个平均在线会话中，48 个执行代码，90 个驻留内存。单环境配额 4 vCPU、12 GiB、20 GB；三项共享系数分别为 1.5、1.1、2 | 分别按各自的活跃数与峰均系数配置，得到峰值约 **218 vCPU、1.63 TiB RAM、2.04 TB 临时 SSD**。CPU 另含启动和恢复开销。 |
| 持久数据 | 对象数据日增约 1.273 TB，保留 21 日，压缩去重后保留 65%；另有固定共享数据 5 TB | 对象存储约 22.38 TB，加已完成工作区的增量 5.76 TB 和独立备份 8.95 TB，得到 **37.09 TB**。 |

默认采用三个可独立调度的 GPU 池。GPU·h 计量执行工作量，预留设备数还受显存上限、并发峰值、整组调度和可接受排队时间约束。成本按预留 GPU、弹性沙箱、存储、网络及监督分别计价。基准情景的下游工作量为 **1,215.88 GPU·h/日**，其中已有实验的替代份额应从组织的净增工作量中扣除。各阶段公式、单价和阈值见[模型说明](model_guide.md)。

## 情景、敏感性与使用边界

AL3 模拟人类主导、AI 协作的任务组合；AL4 模拟人给目标、AI 主导执行；AL5 仅用于受控自主研发压力测试。2027、2028、2030 分别将平均会话数和每日新实验数乘以 **0.75、1.00、1.50**，团队人数、硬件和单价固定。三个时间点和等级组合均为人为设定，缺少采用概率与统计置信区间。

| 时间点 | AL3 协作 | AL4 主导 | AL5 受控自主 |
| --- | ---: | ---: | ---: |
| 2027 | 7 | 62 | 572 |
| 2028 | 7 | 84 | 756 |
| 2030 | 7 | 124 | 1,140 |

表中单位为张 H100 等效卡。只改 2028 年 AL4 的平均训练时长为 **1.5 / 3 / 6 小时**，设备总数依次为 **52 / 84 / 148 张**。据此做团队预算时，优先用作业日志替换每人每日唯一候选数、重试率及每次作业的“卡数 × 时长”，再用推理与沙箱轨迹替换峰值并发、上下文长度和状态驻留时间。实际能安排多少新任务，还要检查实验队列和复核人员的服务能力。
