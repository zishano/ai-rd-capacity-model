# 历史使用量如何进入 30T 预测

按真实任务发起率推算日负载请参见[第一层校准报告](workload/calibration/REPORT.md)。下文记录原时长倍率情景的推导。

## 观测窗口与口径

检索窗口为 2025 年 11 月至 2026 年 11 月。OpenAI 2026 年 11 月 18 日报告的交互图 **Agent workdays across research** 提供 2026-05-03 至 2026-10-18 的 169 个日度图值。取单一序列 Overall Research，每位研究员每个日历日累计的 Agent 使用时长按八小时折成一个工作日，取过去 28 天移动平均。分子可累加并行会话，通常只覆盖交互式使用。首尾图值为 0.5 和 5.7。9 月报告相应图从同一日期开始且与此窗重叠。未给 2025 年 11 月至 2026 年春季或 2026 年 11 月补值。11 月 18 日是发布日期与本预测的年度基准日。[OpenAI 11 月原文](https://openai.com/index/research-acceleration-jagged-frontier/#agent-workdays-research) · [9 月原文](https://openai.com/index/research-acceleration-view-inside-openai/)

[时长序列](observed_agent_workdays.csv)逐行来自 11 月原文嵌入的 Vega-Lite 数据。定位图 ID agent-workdays-research，在 data.values 中筛 series 等于 Overall Research，保留 date 与 value，去除 HTML 重复渲染的相同点。数值已经过发布方平滑、舍入。月份间并无独立的 169 次抽样。

## 第一层：预测每日使用强度

令 t 为距 2026-05-03 的实际日数，y 为上述日度图值。普通最小二乘（每个已发布日等权）给出

    y_hat(t) = −0.29503 + 0.0344928 × t
    使用倍率 G(y) = y_hat(该年 11 月 18 日) / y_hat(2026 年 11 月 18 日)

斜率表示时间每前进一天，研究员日均用量增加约 0.0345 个八小时 Agent 日。截距在样本初段为负，说明直线不能很好刻画早期低使用量；只在观测结束之后用于外推。样本内 R²=0.959。以最后 28 个图值做时间留出检验，前 141 个点拟合的末日预测为 5.14，公布值 5.7；末 28 日 MAE 为 0.62 个 Agent 工作日。滚动窗口会跨越切分日，这项检查只能描述短期误差，无法验证四年外推。

|预测截面|总体 Agent 工作日/研究员日|相对 2026-11-18|
|---|---:|---:|
|2026-11-18|6.57|1.00×|

另检索了覆盖更久的图 **Median Codex, ChatGPT Work & Dots spend per researcher**。其 291 个日度图值覆盖 2026-01-01 至 2026-10-18，从 $0.40 到 $2,414.70；计算口径为每人过去 28 天的日均 API 牌价等值，再对研究员取中位数。以同样的日期归一、单独做 OLS（t 自 1 月 1 日起），直线为 −449.00 + 6.18159t，对应 2030/2026 约 6.88×。价格、模型组合与工具实现均会改变该指标，故只作近十个月的独立参照。两个序列均缺少可核实的完整十二个月覆盖。[牌价序列](observed_api_usage_value.csv) · [原图](https://openai.com/index/research-acceleration-jagged-frontier/#median-spend)

## 第二层：将趋势转换为模型输入

2026 年 11 月定义一个主 Agent 日为一个参考编码任务当量。三档继续使用各自真实轨迹的输入、缓存和输出计量，年际倍率统一由时长趋势提供。每个任务的 Token 数和成功质量、缓存命中比例、任务构成暂取固定。

    日任务当量 = 基准任务当量 × G
    日输入 / 缓存 / 输出 Token = 每题对应计数 × 日任务当量
    日 GPU·h = 当年硬件与精度下的每题推理 GPU·h × 日任务当量

这一步假设研究员累计使用时长的相对增幅，等比例体现在一个主 Agent 承接的任务量上。原图无法区分把更多任务给同一 Agent、增加并行 Agent 数、在工具上等待更久。8.67 是跨场景的需求倍率；56.96 仍只是研究员所有 Agent 合计的预测指标。GPU 层继续使用各年的 SKU、精度和效率工程情景，2029 年仅报告需求输入。

## 外推敏感性

- **拟合窗口。** 固定同一终点，最近 84 日单独拟合得到 9.73×，最近 56 日得到 9.47×，全 169 日得到 8.67×。均用各自直线的 2026-11-18 拟合值归一。这些变体共享数据，不能解读为独立抽样的置信区间。
- **增长落在哪里。** 若新增使用量只有一半体现在单个主 Agent，当量倍率为 1+0.5×(8.67−1)=4.84。按 2030 基准服务配置，每日约 0.516 GPU·h；完全传导时约 0.926；若全部新增使用来自更多并行 Agent，单个主 Agent 仍为 1 个当量、约 0.107 GPU·h。这里的 0%、50%、100% 是敏感性端点。
- **外推跨度。** 从最后观测到 2030 年 11 月约四年，仅有约五个半月的同口径时长图值。线性路径假设绝对增量持续，没有饱和或质量跃迁机制。任务样本 P10–P90 仅刻画编码任务间差异，未含趋势或硬件路线误差。
