研究日期：2026-11-22。范围为第一层公开平滑使用指标，未改变第二层输入默认值、资源公式或团队主流程。

## 本轮结论

单条持续上升线不足以表达预测。本轮保留原四图的团队、类别与颜色编码，新增名义 80%/95% 模型分位带、三条固定抽样路径，以及独立的停滞/回落情景。**模型分位带不是经过验证的四年覆盖率保证；停滞/回落线也没有被赋予概率。**

主展示：[四图与并发区间图集](results/index.html)。可直接打开 PNG/PDF；不会执行网页服务。历史观测不变，月度截面仍为每月 18 日，预测终点 2030-11-18。

## 还有哪些方法值得采用

| 方法 | 为什么值得考虑 | 本轮处理 | 主要限制与来源 |
|---|---|---|---|
| 局部水平状态空间 | 中心可以稳定，未来状态可上升或下降；显式描述状态与观测噪声 | 实现、回测、模拟 | 不自动识别未来增长；噪声参数从短历史估计不稳 [1] |
| 局部线性趋势状态空间 | 斜率本身随机变化，未来可以反转 | 实现，作为探索性对照 | 四年趋势方差可非常大；不能因曲线灵活而默认采用 [1] |
| 阻尼局部趋势状态空间 | 对持续线性增量作收缩，同时保留有正有负的状态扰动 | 实现；固定365天半衰期，另试90/730天 | 半衰期是明确情景，不是本数据识别出的事实；与原 Holt 点预测不完全相同 |
| 简单组合预测 | 避免押注唯一模型；在很少回测起点下不优化复杂权重 | 等权混合无漂移随机游走、OLS、阻尼局部趋势的预测分布 | 权重1/3是人为选择，不是模型后验概率；不保证超过最佳单模型 [2] |
| 贝叶斯状态空间／稳健状态噪声 | 可把增长率、冲击大小和阻尼的不确定性一起建模，厚尾分布可容纳冲击 | 建议后续研究，本轮未拟合 | 仅7–15个窗口点时结果很依赖先验；需外部预算/人群/部署证据约束先验 |
| 区块 bootstrap | 保留局部时间相关性，比对日残差独立抽样合适 | 并发主图已实现两个门槛的配对 28 天残差分块重采样；仅表示趋势拟合不确定性 | 总共约6–8个月，独立时间块非常少；重采样历史无法发现未发生的制度变化 [3] |
| 时序 conformal 校准 | 用历史预测误差校准区间，可搭配任何点预测 | 查阅，当前不启用“95%保证” | 三个滚动起点不足以校准四年；重叠平滑和分布漂移破坏标准交换性条件 [4][5] |
| Prophet | 将未来变化点作为随机变化，直接提供预测区间 | 查阅，未引入额外依赖 | 官方明确警告：未来变化频率/幅度沿用历史，实际覆盖不一定准确；不足一年不加年度季节性 [6] |
| Chronos 等预训练时序模型 | 可作为跨序列预训练得到的分位预测对照 | 查阅，未下载模型或运行推理 | 预训练分布可能不适配内部 Agent 使用指标；仍需本地回测，不能消除四年机制不确定性 [7] |

最小实现组合仍是 **statsmodels + NumPy/SciPy + Matplotlib**，本轮无需安装大模型。若后来获得足够独立的校准窗口，可增加 StatsForecast 的 conformal 接口；批量模型比较可用 sktime。statsmodels/SciPy/sktime 为 BSD-3-Clause，StatsForecast/Chronos 项目为 Apache-2.0，arch 为 NCSA，Prophet 为 MIT；本轮新增实现仅使用既有依赖。

## 实际采用的模型

总量比较六种方法：保持末值中心的随机游走、间隔采样 OLS、局部水平、局部线性趋势、阻尼局部趋势、等权分布混合。新的 OLS 基于间隔窗口点，不等同旧脚本用全部日图值拟合的 OLS；旧代码与结果仍保留，不能把新旧排名差异只归因于算法。

状态模型（一个步长等于该指标的14或28日窗口）为：

\[
\ell_{t+1}=\ell_t+\phi b_t+\eta_t,\qquad
b_{t+1}=\phi b_t+\zeta_t,\qquad
y_t=\ell_t+\epsilon_t.
\]

未阻尼模型取 φ=1；阻尼模型取 φ=2^(−窗口天数/半衰期)。b、η、ζ可以为负，故路径允许下降；中心趋势为正时，期望路径仍可能上涨，这与未来样本路径出现回落并不矛盾。局部水平模型省略b。用卡尔曼滤波估计终点状态及协方差，从预测状态分布和状态/观测扰动联合模拟。收敛失败会尝试第二优化器，仍失败则停止，不默默回退。

高斯模型可能预测负用量，因此**只在输出端把负值截为0**，并记录zero_mass；历史拟合不是删失似然。这会在零点制造概率质量，不能把它当成真实停用概率。下一轮可比较正值支持的状态模型，但对数变换也可能放大四年上尾，不能自动视为解决问题。状态模型区间条件于噪声参数估计，未包含全部参数不确定性。OLS使用Student-t预测抽样，包含其回归参数与残差尺度的不确定性。

组合采用分布混合：从三个成员分别取同样数量的样本，再合并取分位数；**不是先平均三条路径再计算区间**，后者会不合理消除模型分歧。中位数用于主图，mean单独输出。展示路径固定从三个成员各取一条，没有根据是否下降挑选路径。

每个成员默认2400条路径，组合共7200条，随机种子20261122。参数、版本、源文件SHA256均记录。预测点在窗口网格之间做线性插值，再按真实日历提取每月18日；这是窗口目标的插值近似，不是对原始逐日需求的重建。

模拟中位线的小幅抖动也包含有限样本的Monte Carlo误差，不能解释为已识别的未来月度周期。组合与团队参数记录包含各成员的拟合参数，便于复算。

## 数据为什么不支持精确四年误差

从每次训练截止点向前，每隔一个完整窗口取一次观测。完整历史最终保留工作日7点、任务9点、输出15点。effective_points字段表示**这个采样点数，不是严格统计意义上的有效样本量**。减少窗口重叠并不能保证剩余状态独立；首次观测对应的底层窗口还可能早于公开图的起点。

回测沿用训练前60%/70%/80%的起点，预测14/28/56天；参数在每个训练集内重估。单独报告：

- rolling_target：所有公开平滑目标的误差；短提前期仍共享部分底层日期。
- new_underlying_days：只评分提前期至少达到完整窗口长度的点，去掉与训练末窗口共享的日期。相邻评分点和不同起点仍相关。

工作日/任务的28天非重叠评分，每起点只有第28天一个点，合计3点；56天仅1或2个起点，不能对排名作强结论。按MAE/WAPE评价中心，按名义80%/95%覆盖率、95%宽度与WIS评价区间。WIS同时惩罚过宽区间和漏掉实际值；不能靠无限扩大区间证明模型更好。

| 工作日 | 间隔OLS | 1.10 | 0.38 | 100% | 1 |
| 工作日 | 阻尼局部趋势 | 0.14 | 0.17 | 100% | 1 |
| 工作日 | 等权混合 | 0.96 | 0.38 | 100% | 1 |

| 任务 | 等权混合 | 3.25 | 1.45 | 67.2% | 2 |
| 输出Token | 间隔OLS | 87,515 | 70,199 | 61.6% | 2 |

输出Token在28天非重叠评分中，混合模型名义95%带的覆盖也仅64.4%，已经在图上标红。因此主图的带称为**名义模型分位带**，不得宣称覆盖校准已通过，更不得将四年覆盖率当成95%。组合仅提供透明的多假设展示，当前不能声称优于OLS。

## 并发不确定性

把九档占比变换到中心化对数比空间，以联合逻辑正态路径模拟，再经softmax还原。每条路径的九档非负、合计100%，≥16不超过≥4。比较无漂移随机游走和365天阻尼的有符号趋势：趋势可向高档或低档移动，扰动也允许回落。

为减小平滑重叠，按至少28个实际日间隔选点。原报告使用纳入日期窗口，且源表缺7日，所以这里不能保证底层窗口完全独立。零值用0.0005处理；协方差采用50%对角收缩，另试25%/75%。这些均为明确建模条件，只有少量转移点，不声称已识别真实九维过程或人口抽样方差。

28天九档平均百分点误差：无漂移0.93、阻尼趋势1.87；名义95%边际覆盖约94.2%、89.3%。这两种新增方法保留为实验诊断，不替换用户原有双门槛主图算法。没有研究员原始计数，因此没有套用虚构样本量的Dirichlet置信区间。

主图monthly_concurrency.png恢复原双门槛算法：分别对≥4、≥16占比的log(1−p)拟合日历线性趋势，再按末期组内份额拆为九档；直接调用原bin_predict的legacy_log_complement分支。14×5.8英寸单面板、九档颜色、顶部图例、首尾占比和月度横轴均保留。**主趋势逐点与旧模型相同，不用无漂移模型替代。**

主图同时在≥4、≥16的两条堆叠分界叠加趋势拟合不确定性：两个门槛的拟合残差使用相同的28个连续日区块联合重采样，再拟合原来的两条趋势。跳过跨缺失日期的区块。预测样本投影到0≤p16≤p4≤1，保持末期组内拆档规则，所有样本九档之和为100%。图中分界高度是1−p，因此阴影画的是分界高度的分位数，不能误读为门槛占比本身。

实线保留原拟合趋势，半透明阴影表示重采样10%–90%范围，点线表示2.5%–97.5%范围；全部放在同一张九档主图内，不再要求读者查看配套图。区块数量有限且该方法没有模拟未来结构冲击，故**仅为条件趋势拟合范围，不是已校准的预测区间**。main_concurrency.csv、main_concurrency_bands.csv、main_concurrency_metadata.json分别保存原算法中心、两条分界范围、区块/约束投影等参数。

concurrency.csv与predictive_paths.npz中的无漂移/阻尼构成结果仍是原实验数据；对应图命名为concurrency_no_drift.png与concurrency_damped.png，其配套区间和九档边际图区别放在图集折叠的诊断区。**九个上界或下界不能相加，也不能堆成100%面积图**。恢复主算法不表示它的回测优于朴素基线，也不改变其他三张主图。

## 回落情景与资源接口

scenarios.csv独立记录：维持模型中心、2028-01-18起保持该日水平、该日起每年回落10%或20%。日期与回落率均为假设，用于回答“如果出现收缩会怎样”，没有历史证据支持其发生概率，也未用于调宽统计带。

18类任务与输出暂沿用历史末84日份额，所有类别合计精确等于图中的总量中位数；类别构成未来变化未识别。工作日团队分别拟合，总体不是五个团队曲线相加。旧第一层workload.csv及第二层输入未被替换，新模型尚不足以作为唯一资源预算依据。

## 运行与文件

```bash
python -m pip install -r analysis/agentic_30t_forecast/workload/trend_models/requirements.txt
python -B -m analysis.agentic_30t_forecast.workload.trend_models.uncertainty.run
python -B -m analysis.agentic_30t_forecast.workload.trend_models.uncertainty.check
```

## 公开来源与本轮访问记录

1. [statsmodels：UnobservedComponents结构时序模型](https://www.statsmodels.org/stable/generated/statsmodels.tsa.statespace.structural.UnobservedComponents.html)；[条件模拟接口](https://www.statsmodels.org/stable/generated/statsmodels.tsa.statespace.structural.UnobservedComponentsResults.simulate.html)。官方列出局部水平、随机游走、局部线性趋势的状态方程。本轮已读取。
2. [sktime：EnsembleForecaster](https://www.sktime.net/en/stable/api_reference/auto_generated/sktime.forecasting.compose.EnsembleForecaster.html)。官方支持均值/加权等点预测组合；本轮自行实现分布混合，不宣称该接口直接实现当前分位数方法。
3. [arch：时间序列bootstrap实现源码](https://github.com/bashtage/arch/blob/main/arch/bootstrap/base.py)。含移动区块、循环区块、平稳bootstrap。本轮读取源码；文档站返回403，访问结果留档。
4. [StatsForecast：Conformal Prediction](https://nixtlaverse.nixtla.io/statsforecast/docs/tutorials/conformalprediction.html)。官方工具使用预测误差进行区间校准；其一般覆盖宣传不能直接移用于本项目的重叠窗口与四年漂移。
5. [Barber等：Conformal prediction beyond exchangeability](https://arxiv.org/abs/2202.13415)。论文明确讨论交换性假设、分布漂移与加权校准。三个回测起点不能提供足够独立校准证据；标准有限样本95%校准若仅3个分数，分位秩会超过样本数，不能据此生成有限且有保证的95%区间。
6. [Prophet：Uncertainty Intervals](https://meta.github.io/prophet/docs/uncertainty_intervals.html)。官方原文：未来趋势变化频率/幅度假设与历史相似，并提示“you should not expect to get accurate coverage”。本轮跟随旧文档链接迁移后读取。
7. [Chronos官方仓库](https://github.com/amazon-science/chronos-forecasting)。提供预训练时序模型；本轮仅调研，不报告未运行的性能。
