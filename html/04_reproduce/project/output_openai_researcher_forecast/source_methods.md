# 指定研究员数据的方法与推演边界

本次唯一文章来源是 OpenAI 于2026年9月6日发布的[《研究加速：OpenAI内部视角》](https://openai.com/zh-Hans-CN/index/research-acceleration-view-inside-openai/)，于2026年11月21日重新下载中文版。主预测仅使用用户指定的[18类输出Token图](https://openai.com/zh-Hans-CN/index/research-acceleration-view-inside-openai/#chart-4QLdZ4iw0n4L9rYGTvteZK)。页面锚点已对应到本次下载的 `chart_08.json`；原网页、图表数据和下载哈希保存在 [source_downloads](source_downloads/)。同页工作时长单列为补充条件预测；并发比例、花费分位和部门相对指数仅保留辅助历史统计，均不作为主输出Token预测的输入。

**主序列是处理后的人均输出量。** 指定图覆盖2026年1月20日至8月15日，将研发活动分成18类。官方从在职研究员工的内部编码会话中抽样2%，还原估计输出量；对每日非零抽样用户按输出总量的P95设置上限，超出者各类别同比例缩减。标注／评分以及无法匹配研发类别的活动不进入图中，结果经过14日后向平滑。单位是每研究员工每日输出Token，不是每个Agent、每次任务或每次模型调用的Token，也不是用户日输出P95本身。图表数值受抽样、分类和截尾影响，不等于完整账单。

文章中的“研究人员”泛指研究组织成员，包含基础设施、项目管理等支持人员。百人换算采用这100人与公开人群具有相同人均使用强度及活动构成的条件：各类人均值乘100再合计。因此结果是同口径的条件估计，不是这支团队的实测总量，也没有恢复被截掉的高用量尾部。另一张部门相对增长图明确包含隐藏推理Token，但指定18类图的独立方法未重申其完整范围；本报告沿用“官方输出Token”，不把它直接等同于全部模型执行Token。

**2027–2030采用三种透明趋势情景。** 主拟合取末日及其前89个自然日，即最近90自然日；以实际日期间隔为横轴，18类分别计算OLS斜率，保留官方14日平滑，不再拼成28日。以各类最后公开值为锚点，每年8月15日为代表日。设该值为 `y₀`、日斜率为 `b`、距末日天数为 `d`，三情景分别为：

- 保持末值：`y(d) = y₀`。
- 线性延续：`y(d) = max(0, y₀ + b × d)`。
- 斜率逐年衰减：`y(d) = max(0, y₀ + b × (1 − exp(−λd)) / λ)`，其中 `λ = ln(2) / 365.25`。

各类别预测、截零后合计，再换算百人。斜率每365.25天减半是本次明确设定的情景假设，不是OpenAI预测。年度柱表示代表日的平滑日强度，不是全年累计量；输出除以86,400仅表示24小时摊平速率，不提供峰值或服务时延保证。

90日窗口是一项分析选择，并不意味着它已被证明最准确。另列全历史、60日、120日拟合窗口，保持其他公式与锚点相同，用于检查近期增长与长期增长差异。14日平滑导致相邻点相关，样本点数不等于独立样本数；窗口敏感性和三情景都不是统计置信区间。半年多观测无法验证四年后的组织规模、工具能力和活动结构，因此不将线性结果称为确定需求或上下界，也不把三种趋势分别解释成更多会话、更长任务或混合机制。

短期留出检验对输出序列保留90日训练、28个日期的隔离区及末尾28日评估；仅用于检查近端偏差。时长序列只有105日，不足以执行同一检验，明确记为未评估。时长的120日敏感性实际采用全部105日，因而与其全历史结果相同。上述检查不能替代2027–2030的实测验证。

**辅助工作时长有独立分母。** 同页工作日图将符合条件的Agent墙钟时长加总，每8小时计一个Agent工作日；研究组织每名员工在每个自然日按8小时计一个研究人员工作日，分母不是仅周一至周五的出勤工时。图采用过去28个自然日的窗口，并按官方规则排除公司假期。父Agent与子Agent分别计时，包含自动审查线程；排除 `codex exec`、标题生成、记忆整理后台任务、工作区Agent、内部评估及已知测试流量。同一轮次中相邻服务器事件间隔超过30分钟的部分不计活跃时间。该比率乘8、再乘100，可得到相同口径的百人参考日累计小时；除24得到平滑的平均活动当量。它不是GPU忙时或LLM请求并发，也不与18类输出按逐任务关联。本报告在历史值之外，对该序列独立应用90日OLS、末值锚定及三趋势，作为同页补充条件预测；它保留自身28日平滑和假期规则，不参与主输出Token预测，也不能与输出相除得到单任务速度或时长。

**辅助并发与花费分位不能变成团队总量。** 并发图统计研究组织员工中，过去7天曾有至少4个Agent重叠运行者的比例，包含管理者及不在岗员工，按PDT日期并排除公司假期；重叠须超过30秒，父子Agent分别计数。乘100只得到同强度百人中达到过该阈值的人数，不能再乘4当作团队同时峰值。花费图是每日个人中位数或P90的周平均，以2026年9月3日API价格折算，并非真实账单；分位数不能乘100充当团队总开销。二者均只保留历史，不用于2027–2030容量预测。

**辅助相对指数保留相对单位。** 部门增长图合并每名员工的ChatGPT与Codex输出，明确包含隐藏推理、可见答复、代码和工具调用；排除公司假期后折算为28日等效量。每日部门值取全体在职正式员工（包括零使用者）的中位数，再相对该部门2025年11月1日中位数表示。该指数不能恢复绝对Token，也不能乘100得到团队输出；它与指定18类图的14日人均输出序列分别保留。

**保持未知的指标。** 本页没有可用于该人群的任务发起总量、逐任务输入／输出账单、调用次数或请求上下文分布。实验强度、成功率及分类样本数也不能替代任务发起数。因此每任务Token、输入和缓存量、缓存命中率、完整推理FLOPs、团队KV、峰值请求数、内存与网络流量均不从这些图反推；对应缺失量保持未知。
